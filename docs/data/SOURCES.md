# AgriPulse — Official Data Sources Log (`SOURCES.md`)

Merged from `Teammate-A/data/SOURCES.md` and `Teammate-B/data/SOURCES.md`.
Every dataset and live API used in AgriPulse is logged below with its publisher, URL or Resource ID, license and verification notes. Each team's rows are kept exactly as that team wrote them.

> **Note:** Dataset IDs repeat across the two teams (for example `A2`, `A4`, `A6`, `A7`). The same ID does not always mean the same source. Check the team heading before you use an ID.
