# A6 — Canonical Districts & Coordinates Table

## Methodology & Verification
- **Dataset ID:** A6
- **Purpose:** Canonical reference list for all 34 Maharashtra agricultural districts.
- **Rule #6 Compliance:** Contains `name_variants` column (e.g. `Ahmednagar -> Ahilyanagar`, `Aurangabad -> Chhatrapati Sambhajinagar`) ensuring seamless joins across weather, mandi, and yield databases.
- **Columns:** `district`, `hq_name`, `latitude`, `longitude`, `district_code`, `name_variants`.
